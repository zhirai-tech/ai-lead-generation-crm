## 3. 安全检查（真实 HTTP）

脚本：`node scripts/verify-safety.mjs http://127.0.0.1:4173`
针对 seeded demo 工作空间，结果 **15/15 通过**：

- 管理员登录；发送时间窗临时放宽（验证后恢复）。
- 已批准草稿进入队列 → Worker（真实后台任务）发送成功 → 草稿 `sent` + 生成 `email_messages` + 用量/审计。
- 人工接管后：创建并批准第二封草稿 → 发送被服务端以 409 拒绝（`CONFLICT`），接管时未发送任务被取消。
- 抑制名单：添加邮箱抑制 → 发送被 409 拒绝。
- 公共退订链接：预览接口返回脱敏邮箱 → POST 退订 → 抑制记录出现（验证后清理）。
- 恢复发送窗口。

另验证：

- 未登录访问受保护 API → 401；缺少 CSRF 的写请求 → 403；viewer 修改设置 → 403。
- 邮箱账户凭据仅返回掩码；跨工作空间读取被隔离（测试覆盖）。
- 前端页面无内联脚本/样式，CSP 生效；静态资源不暴露 `server/**`、`docs/**`、运行数据。
